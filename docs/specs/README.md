# Specs

**Purpose:** Keep cross-cutting platform delivery specs, audit rules, and post-push workflow requirements.

**Last updated:** 2026-04-24

## Scope

Specs here apply to the platform repository itself. Shared ecosystem workflow
changes must stay aligned with upstream specs in `styio` and `styio-spio`.

Technology-stack, internal-component, open-source-component, and dependency-manifest inventory maintenance rules live in [TECHNOLOGY-COMPONENT-INVENTORY.md](./TECHNOLOGY-COMPONENT-INVENTORY.md).

Registry-management reviews must prove the minimum hosted-service coverage for
publish, verify, mirror freshness/replay, offline client fallback, service/cache
boundaries, and security policy before the platform side is considered
measurable.
